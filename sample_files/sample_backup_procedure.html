Backup and Recovery Procedure

Brightwater Analytics Pvt. Ltd. - IT Operations. This procedure describes how production data is backed up and restored.

Backup Schedule

  • Production databases must be backed up daily.
  • File shares are backed up weekly.
  • Backups must be retained for 90 days.

Responsibilities

IT Operations is responsible for monitoring backup jobs and investigating failures on the next working day.

Backup failures are not reported to System Owners.
