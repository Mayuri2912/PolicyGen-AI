# HR procedure reference rules

Reviewed on 16 October 2026 against the user-supplied 005A tracked and 005B accepted HR procedure. 005A contains tracked insertions/deletions; 005B has no tracked revisions. Original files remain unchanged and are not committed.

- HR lifecycle: CV screening, interviews, lawful screening/consent, competence, confidentiality, induction, role changes, disciplinary interface and offboarding.
- Include organisation-managed and customer-managed projects; customer asset and access actions require customer authority and evidence of completion.
- HR references separate risk, incident and JML procedures without reproducing their registers, scoring, investigation or escalation workflows.
- Remove standalone HR risk-controls, incident-reporting and reference sections. Explain abbreviations in Definitions.
- Keep one scope, one combined objectives/principles section and one roles table. Do not reproduce the reference's empty objectives heading, duplicated scope or stale contents entries.
- HR exports use a compact document-control table, no visible statement/finding IDs or Basis column. Evidence remains in stored content and reviewer tools. Preserve approval/readiness controls in the app.
- Retain the existing Sapres template typography, page furniture and branding. Disable inherited heading numbering because the renderer already numbers headings, preventing doubled heading/TOC numbers.
- For Sapres Technologies GmbH only, the accepted reference supplies asset return within five business days, credential revocation immediately on the final working day, and annual/material-change review. Conflicts with current evidence must be flagged. Do not impose these company-specific values on other organisations.
- Catalogue code S-15 remains stable. The reference's I-05 identifier is not silently assigned across all customers or substituted for the catalogue ID.

Validation uses offline generation and both export formats. Word page rendering could not run locally because LibreOffice is unavailable; OOXML and PDF layout checks are used and this limitation must be reported.
